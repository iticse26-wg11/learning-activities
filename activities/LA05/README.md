# AI Model Pipeline

**Related ILOs:** MM02, EPR03
**Type:** In-class, Individual and Small-group, Unplugged · **Duration:** 45 minutes · **Scale:** two or more small groups

## Description

In small groups, students examine a simplified GenAI pipeline covering data collection, pre-training, fine-tuning and RLHF, user prompts, token prediction, output generation, and data storage. Using a worksheet, they match each stage with a brief description and identify associated limitations or risks, such as biased data, dataset cutoff dates, bias in human feedback, disclosure of sensitive information, misleading outputs, unclear data-retention practices, and loss of control over where data is stored, accessed, or used. They then explain the model-development process in sequence, describe how development decisions can affect later outputs, and evaluate who is responsible for preventing or addressing risks of misuse, manipulation, and threats to data sovereignty across the pipeline.

## Keywords

Model lifecycle, Data risks, RLHF (Reinforcement Learning from Human Feedback), Data sovereignty, Responsibility

- Basic familiarity with the GenAI pipeline as in CS02
