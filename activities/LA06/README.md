# LLM Output Evaluation and Fact-Checking

**Related ILOs** (at the end of the course, students should be able to …)
- [EPR04](https://github.com/iticse26-wg11/intended-learning-outcomes/blob/main/ilos/EPR04.md): explain the shortcomings of GenAI outputs (e.g., accuracy, reliability) and recognize the need to follow the appropriate policies and regulations within the context where the outputs will be used.

**Type:** In-class, individual, digital · **Duration:** 1 hour · **Scale:** Small and large cohorts

## Description

To introduce the exercise, the instructor first distributes a sample worksheet featuring one example prompt alongside 3–4 contrasting outputs from different GenAI systems. The class reviews the prompt and the outputs together to practice identifying differences in areas such as style, accuracy, how well the output follows the prompt, and tone.

Students are then provided with a scenario (e.g., creating a plan for a class party) and submit the same prompt to at least two different GenAI systems of their choice. Instructors may select GenAI systems with different capabilities or design characteristics, as long as each is reasonably suited to the assigned task.

Students compare the output from each GenAI system and identify the differences, shortcomings, and limitations of each tool. Each student then selects the strongest output based on predefined criteria (e.g., best alignment with the prompt, level of detail) and evaluates whether it complies with a short provided policy or set of rules, identifying any parts of the output that may conflict with these requirements.

To guide their analysis, students should use the following comparison discussion prompts as a starting point:

- Which GenAI system followed all aspects of the original prompt most accurately?
- What unique strengths or features did each GenAI system exhibit?
- Where did each GenAI struggle, fail, or make incorrect assumptions?
- Did either output violate any aspect of the policy or ethical constraints?

In larger cohorts, the instructor could ask students to pair up or form small groups to exchange findings, discuss their selected outputs, and compare how different GenAI systems handled the same scenario. The session closes with the instructor leading a discussion of differences and shortcomings in GenAI outputs and the importance of evaluating outputs against relevant requirements and policies.

## Keywords

Model comparison, fact-checking, policy compliance, output quality
